# IDPS Course

Интерактивный учебный портал по дисциплине «Системы обнаружения и предотвращения вторжений».

## GitHub Desktop workflow

1. Внести изменения.
2. Проверить **Changes**.
3. Commit to `main`.
4. **Push origin**.
5. Дождаться `Deploy GitHub Pages`.

### v2.6 editorial rework

Глава 2 переработана без повышения версии после проверки визуальной и когнитивной нагрузки.

Изменения:
- удалена перегруженная интерактивная карта видимости;
- удалён отдельный JavaScript для неё;
- сокращено количество разделов и декоративных блоков;
- введение построено вокруг одного инцидента и разных наблюдаемых следов;
- вместо общей сложной схемы используются четыре независимые вкладки: сеть, хост, Wi‑Fi и поведение;
- классификация IDPS объясняется через источник данных, а не через запоминание аббревиатур;
- центральным стал инженерный алгоритм «что обнаруживаем → какой след → где наблюдаем → какой источник → какой класс системы»;
- итоговый сценарий показывает совместное использование нескольких источников.
