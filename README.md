# IDPS Course

Учебный курс по системам обнаружения и предотвращения вторжений (IDS/IPS) для студентов направления информационной безопасности.

Курс объединяет теорию, самостоятельную работу, лабораторные занятия и проверку знаний. Основная идея курса — связывать техническое событие с наблюдаемым следом, источником данных, логикой обнаружения и обоснованным выводом.

## Открыть курс

Опубликованная версия: https://11ndra.github.io/spvo/

## Структура репозитория

- `docs/course/` — теоретические материалы;
- `docs/labs/` — лабораторные и практические работы;
- `docs/resources/` — контрольные вопросы, тестовый тренажёр, СРО, глоссарий и источники;
- `tools/` — проверки сборки и целостности материалов;
- `mkdocs.yml` — конфигурация сайта.

Технические отчёты о разработке, внутренние матрицы соответствия и release notes не являются частью учебного содержания сайта.
