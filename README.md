## v2.10 — Detection quality, Base-Rate Fallacy and tuning

Полностью переработана Глава 6:
«Как измерять качество обнаружения».

Основной вопрос:
«Как понять, что детектор действительно полезен, а не просто часто срабатывает?»

Добавлено:
- TP / FP / TN / FN как четыре возможных результата;
- объяснение, почему accuracy может быть бесполезной при сильном дисбалансе классов;
- recall и precision с инженерной интерпретацией;
- интерактивный Base-Rate Lab;
- демонстрация влияния prevalence, TPR и FPR на реальное количество alert;
- Base-Rate Fallacy без упрощённого тезиса «99.9% детектор всегда плох»;
- trade-off между FP и FN;
- tuning как сохранение полезного detection coverage, а не просто уменьшение числа alert;
- Alert Fatigue как эксплуатационный эффект плохого качества detection;
- минимальная методика тестирования сигнатуры: malicious / benign / similar benign / modified malicious;
- связь метрик с критичностью актива и ценой автоматического prevention.
