# Лабораторная работа №1

## Основы IDS/IPS и первое знакомство с Suricata

### Цель

После выполнения лабораторной работы студент должен уметь:

- объяснить назначение IDS и IPS;
- назвать основные классы IDPS;
- объяснить отличие IDPS от базового межсетевого экрана;
- установить Suricata;
- выполнить первоначальную настройку;
- получить первый alert;
- найти событие в `eve.json`;
- объяснить, почему alert не равен подтверждённой атаке;
- экспериментально увидеть различие Detection и Prevention.

## Практический стенд

В первой версии курса используется облегчённый **LabBox**:

```text
Client namespace
      ↓
Suricata Sensor
      ↓
Target namespace
```

Физически стенд может работать внутри одной Ubuntu VM.

!!! note "Почему одна VM"
    Цель лаборатории — изучить IDPS, а не потратить занятие на эксплуатацию трёх виртуальных машин. Network namespaces сохраняют логическое разделение узлов при значительно меньших требованиях к RAM.

## Этапы

1. Проверка LabBox.
2. Установка Suricata.
3. Настройка `HOME_NET`.
4. Наблюдение нормального HTTP-трафика.
5. Создание тестовой сигнатуры.
6. Получение первого alert.
7. Анализ `eve.json`.
8. Реалистичный безопасный Path Traversal-паттерн.
9. Переход IDS → IPS.
10. Мини-эксперимент с False Positive.

> Детальная пошаговая инструкция будет добавлена после фиксации первой версии LabBox.
