# Visual assets

Рекомендуемая структура:

- `diagrams/` — SVG-схемы процессов и архитектуры;
- `topologies/` — сетевые топологии;
- `screenshots/` — Wireshark, Suricata, Wazuh и т.п.;
- `gifs/` — короткие учебные анимации;
- `icons/` — локальные иконки, если они понадобятся.

## Рекомендуемые форматы

- Диаграммы: **SVG**
- Скриншоты: **WebP/PNG**
- Короткие анимации: **GIF/WebP**

## Правило добавления ассета

Сначала добавьте реальный файл, например `docs/assets/images/diagrams/<имя-схемы>.svg`, затем вставляйте его в учебную страницу относительной ссылкой, проверенной при сборке сайта.

Не используйте в документации фиктивные пути к отсутствующим изображениям. Подпись должна описывать фактический смысл схемы и не сводить различие IDS/IPS к упрощению `IDS = passive`, `IPS = inline`.
