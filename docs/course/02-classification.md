# 2. Классификация IDPS

В курсе используется классическая архитектурная классификация NIST SP 800-94 как исторически важная основа. При этом современные продукты часто совмещают несколько функций.

## Network-based IDPS

Анализирует сетевой трафик.

В практических работах основным NIDS/NIPS будет **Suricata**.

## Host-based IDPS

Работает с телеметрией конкретного конечного узла:

- процессы;
- файлы;
- аутентификация;
- системные журналы;
- FIM;
- Linux Audit/eBPF;
- Windows Event Log/ETW.

В дальнейших работах будет использоваться **Wazuh**.

## Wireless IDPS

Специализируется на беспроводной среде: rogue AP, нарушения политики WLAN, подозрительные management frames.

## Network Behavior Analysis

Опирается на характеристики сетевого поведения и потоков:

- периодичность;
- направления обмена;
- объём;
- продолжительность;
- аномальные сетевые шаблоны.

Для части таких задач в курсе будет использоваться **Zeek** и flow telemetry.
