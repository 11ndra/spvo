# Классификация IDPS

<div class="page-goal"><strong>Цель:</strong> понимать, почему одной IDS недостаточно для наблюдения всей инфраструктуры.</div>

Классическая классификация NIST SP 800-94 выделяет четыре основных класса IDPS.

## Network-based IDPS
Анализирует сетевой трафик. В курсе основной NIDS/NIPS — **Suricata**.

## Host-based IDPS
Работает с телеметрией конечного узла: процессы, файлы, аутентификация, FIM, Linux Audit/eBPF, Windows Event Log/ETW. В курсе — **Wazuh**.

## Wireless IDPS
Специализируется на беспроводной среде: rogue AP, неизвестные WLAN, нарушения политики Wi-Fi.

## Network Behavior Analysis
Ищет закономерности и отклонения в потоках: периодичность, объёмы, направления, продолжительность. В курсе — **Zeek** и flow telemetry.

| Класс | Основной источник | Хорошо видит | Плохо видит |
|---|---|---|---|
| NIDS/NIPS | Сеть | Flow, протоколы, сетевые атаки | Локальные изменения host |
| HIDS/HIPS | Endpoint | Файлы, процессы, audit | Полную картину сети |
| WIDS/WIPS | 802.11 | Wi-Fi среду | Проводную сеть |
| NBA/NTA | Flow/behavior | Аномалии и закономерности | Не всегда точную причину |
