# Качество детектирования

<div class="page-goal"><strong>Цель:</strong> понимать, что хорошая IDS — это не система с максимальным количеством alerts.</div>

| Реальность | Сработало | Не сработало |
|---|---|---|
| Угроза есть | **True Positive** | **False Negative** |
| Угрозы нет | **False Positive** | **True Negative** |

IDS + FP обычно означает лишнюю работу аналитика. IPS + FP может означать автоматическую блокировку легитимного сервиса.

Слишком широкое правило повышает риск FP. Слишком узкое правило повышает риск FN.
