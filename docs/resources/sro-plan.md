# Самостоятельная работа обучающегося (СРО)

СРО по дисциплине рассчитана на **15 недель по 7 часов**. В рабочей программе недели 1–14 связаны с курсом Cisco **Endpoint Security**, а неделя 15 отведена под проект.

Эта страница **не заменяет материалы Cisco** и не воспроизводит их содержание. Она показывает, как связать официальную СРО с материалами курса и какие evidence сдавать преподавателю.

## Что считать evidence по Cisco

Доступные элементы интерфейса Cisco могут отличаться. Поэтому преподаватель может принимать один из вариантов:

- запись/результат о завершении модуля, если платформа его предоставляет;
- выгрузку/оценку, доступную преподавателю;
- короткий учебный журнал по официальной теме недели.

Курс не требует конкретного скриншота кнопки или страницы Cisco, если такой формат отдельно не утверждён преподавателем.

## Принцип СРО

СРО должна дополнять лаборатории, а не превращаться в копирование конспекта. Для каждой недели студент связывает внешнюю тему с одним из вопросов:

```text
что защищаем?
какая угроза / слабость рассматривается?
какой источник evidence доступен?
какая защитная мера применима?
какие ограничения остаются?
```
