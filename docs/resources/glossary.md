# Глоссарий

| Термин | Значение |
|---|---|
| IDS | Intrusion Detection System |
| IPS | Intrusion Prevention System |
| IDPS | Обобщённое обозначение detection/prevention systems |
| NIDS/NIPS | Сетевые IDS/IPS |
| HIDS/HIPS | Хостовые IDS/IPS |
| WIDS/WIPS | Беспроводные IDS/IPS |
| NBA/NTA | Анализ сетевого поведения / сетевого трафика |
| Alert | Событие, сформированное системой обнаружения |
| Signature | Формализованное условие обнаружения |
| TP | True Positive |
| FP | False Positive |
| TN | True Negative |
| FN | False Negative |
| Inline | Размещение средства в пути трафика |
| SPAN | Зеркалирование трафика на коммутаторе |
| TAP | Средство съёма копии сетевого трафика |
| Telemetry | Набор наблюдаемых данных о системе/событиях |
| Flow | Логическое сетевое взаимодействие между endpoints |
| EVE JSON | Структурированный формат событий Suricata |
| HOME_NET | Переменная Suricata для защищаемой сети/адресов |
| Defense-in-Depth | Эшелонированное применение нескольких защитных контролей |
| Detection Engineering | Проектирование, тестирование, tuning и сопровождение логики обнаружения как воспроизводимого инженерного артефакта |
| Observable | Наблюдаемый признак активности, доступный выбранному источнику данных |
| Sticky buffer | Protocol-aware область данных Suricata, к которой применяются последующие detection keywords |
| Regression test | Повторяемая проверка, что изменение правила не нарушило ранее ожидаемое поведение |
| Positive test | Тестовый случай, который должен создавать совпадение |
| Negative test | Тестовый случай, который не должен создавать совпадение |
| Variant test | Изменённый вариант интересующего поведения для проверки устойчивости detection |
| fast_pattern | Content-паттерн, используемый движком Suricata для предварительного отбора кандидатов |
