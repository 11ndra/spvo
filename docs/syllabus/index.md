# Темы дисциплины

Теоретическая часть организована по **15 темам рабочей программы**. У каждой темы есть собственная страница с кратким введением, вопросами для самопроверки и ссылками на подробные материалы курса. Такая структура позволяет идти последовательно по программе и при необходимости углубляться в архитектуру IDS/IPS, правила, оценку эффективности и корреляцию событий.

Для более глубокого изучения курс отдельно разбирает архитектуру и точки наблюдения, правила обнаружения, ограничения и ложные срабатывания, оценку эффективности, интеграцию с SIEM/EDR, сопровождение правил и другого detection content и корреляцию нескольких источников.
