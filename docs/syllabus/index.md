# Программа дисциплины и навигация

Курс построен вокруг **15 тем рабочей программы**. Некоторые темы используют общий учебный материал: например, модель OSI, криптография и безопасность сетевых протоколов рассматриваются в одном большом модуле о протоколах и наблюдаемости. Это сделано для связности, а не для изменения содержания дисциплины.

## Углубление по IDS/IPS

Помимо обязательных тем, курс отдельно разбирает правила обнаружения, ограничения и ложные срабатывания, оценку эффективности, интеграцию с SIEM/EDR, сопровождение detection content и корреляцию нескольких источников. Эти материалы находятся в разделе **«Углубление IDPS»** навигации.

СРО рассчитана на 15 недель по 7 часов. Для каждой недели определены самостоятельное задание, сдаваемый результат и критерий выполнения; недели 1–14 связаны с Cisco Endpoint Security, неделя 15 — с итоговым проектом.
