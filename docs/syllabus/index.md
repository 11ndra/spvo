# Темы дисциплины

Теоретическая часть организована по **15 темам рабочей программы**. Каждая тема содержит полноценное учебное объяснение, примеры и интерактивную самопроверку непосредственно на своей странице. Для последовательного изучения не требуется открывать дополнительные главы. В каждой теме обязательные вопросы рабочей программы рассматриваются в связи с IDS/IPS: наблюдением, анализом, обнаружением, предотвращением и доказательной интерпретацией результатов.
