# 13. Безопасность веб-сервисов

Веб-сервис одновременно зависит от сетевого транспорта, приложения, identity-механизмов, сессий, API и хранилищ. Поэтому его безопасность нельзя свести к одному WAF или IDS-сигналу.

OAuth 2.0 решает задачи делегированной авторизации, а OpenID Connect добавляет слой аутентификации/идентичности поверх OAuth 2.0. Принятие корректного токена не заменяет проверку прав на конкретный объект или функцию API.

Для защиты веб-сервисов также важны TLS, безопасное управление сессиями и cookie, валидация входных данных, CSP/CSRF-защита, rate limiting, обновление компонентов, резервное копирование, логирование и мониторинг.
