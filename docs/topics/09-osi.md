# 09. Эталонная модель взаимодействия открытых систем (OSI)

Модель OSI делит сетевое взаимодействие на семь функциональных уровней. Она нужна как координатная модель: помогает отделять физическую передачу, канальный обмен, маршрутизацию, транспорт, сеанс, представление данных и прикладные функции.

Для IDS/IPS OSI полезна не как «семь коробок внутри сенсора», а как язык для описания того, **какие данные и на каком уровне доступны**. MAC-адрес, IP-адрес, TCP-состояние и HTTP-поле относятся к разным представлениям одного обмена.

Реальные протоколы не всегда укладываются в OSI буквально, поэтому модель следует использовать для анализа и диагностики, а не как описание внутренней реализации каждого продукта.
