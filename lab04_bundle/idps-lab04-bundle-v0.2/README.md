# Пакет ЛР №4 v0.2

Работа демонстрирует три разных основания решения над **одним и тем же форматом событий**:

1. точное совпадение заранее заданного признака;
2. детерминированное условие над серией событий;
3. отклонение от построенной базовой линии.

Учебный HTTP-сервис пишет все события в `/var/tmp/idps-lab/lab4-access.jsonl`.
`server/detectors.py` читает этот же журнал во всех трёх режимах.

Скрипт `detectors.py` — **учебная модель**, а не промышленная IDS. Его задача — изолировать различия методов до перехода к синтаксису правил Suricata в следующей главе.

Перед работой:

```bash
sudo bash server/setup-server.sh
sudo bash server/preflight-server.sh
```

На клиенте:

```bash
bash client/check-client.sh
```
